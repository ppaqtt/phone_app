清笺隐私政策

完全本地化的笔记应用 · 您的数据只属于您

生效日期：2026年06月12日 最近更新：2026年06月18日 版本：v1.20.24

我们的隐私承诺

您的数据只属于您。我们不上传、不收集、不追踪。

我们做的

  • 所有数据存储在您设备本地
  • 无需注册账号即可使用
  • 仅在您主动点击「检查更新」时联网
  • 卸载应用即彻底删除全部数据

我们不做的

  • 不上传笔记内容到任何服务器
  • 不收集邮箱、手机号、位置、通讯录
  • 不接入广告 SDK，不做行为分析
  • 不出售或共享您的数据给第三方

📋 一、信息收集范围

1.1 您主动提供的信息（本地存储，不上传）

信息类型 具体内容 存储位置
笔记内容标题、正文、列表、待办、标签设备本地数据库
图片从相册选择或拍照插入的图片设备本地存储
音频选择插入的音频文件设备本地存储
涂鸦在白板上绘制的内容设备本地存储
表格插入的表格数据设备本地存储
提醒时间为笔记设置的提醒时间设备本地数据库
笔记颜色为笔记选择的便签色设备本地数据库
应用锁 PINSHA-256 加盐哈希后的 PIN设备本地加密存储

1.2 自动收集的信息（仅本机，不上传）

  • 设备信息：Android 版本、设备型号（仅用于兼容性判断）
  • 日志信息：应用崩溃日志（仅本机保存，用于排查问题）

1.3 明确不收集的信息

  • 账号、邮箱、手机号
  • GPS 精确位置或粗略位置
  • 通讯录、短信、通话记录
  • 设备唯一标识（IMEI / IMSI / MAC 地址）

🔧 二、信息使用方式

信息 用途
笔记内容在本机显示、编辑、保存
图片 / 音频 / 涂鸦 / 表格在笔记中显示、编辑、保存
提醒时间在指定时间通过系统通知提醒您
应用锁 PIN验证进入应用或切回前台时的解锁操作
设备信息仅用于判断 API 兼容性，不外传

🛡️ 三、信息存储与安全

  • 存储位置：所有数据存储在您设备本地的 Room / SQLite 数据库中
  • 存储期限：永久存储，直到您主动删除笔记或卸载应用
  • 数据隔离：利用 Android 系统沙箱机制，其他应用无法访问
  • 云端备份：不自动备份到云端；您可在「设置 → 数据备份」中手动导出到本地 JSON 文件

🔑 四、应用锁（PIN）说明

项目 说明
PIN 长度4-8 位，由您自行设置
存储方式SHA-256 + 固定盐值哈希存储，不可逆
网络传输PIN 不会发送到任何服务器
解锁有效期成功解锁后 5 分钟内回到前台无需再次输入；超过 5 分钟或主动「立即锁定」则重新要求输入
忘记 PIN不提供找回功能（因未上传）；可选择「忘记 PIN → 清除所有数据并重置应用锁」恢复使用（会删除所有笔记，请先备份）

🤝 八、信息共享

我们不会

  • 将您的笔记内容出售给第三方
  • 与广告平台共享您的数据
  • 与任何第三方分析平台共享您的数据
  • 在用户未授权的情况下访问您的通讯录、位置、短信

我们仅在以下情况共享

  • 您主动通过分享功能导出的笔记
  • 法律法规要求（如配合司法机关调查）
