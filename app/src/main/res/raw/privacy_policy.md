## 一、我们如何收集和使用您的个人信息

我们收集的您的个人信息途径主要为：您主动提交给我们的信息、我们直接获取的您在使用我们的产品或服务时产生的信息。我们仅会基于本《隐私政策》声明的目的处理您的个人信息。**但请您注意，由于软件版本存在差别，服务功能配置可能存在差异，我们收集的信息取决于您实际使用产品时的情况。**

### 1.1 笔记内容（本地存储，不上传）

为了向您提供笔记记录与管理服务，我们需要获取您主动创建的笔记内容信息，**全部存储在您的设备本地，不会上传至任何服务器**。

| 信息类型 | 具体内容 | 存储位置 | 不提供的后果 |
|---------|---------|---------|------------|
| 笔记内容 | 标题、正文、列表、待办、标签 | 设备本地数据库 | 无法使用笔记功能 |
| 图片 | 从相册选择或拍照插入的图片 | 设备本地存储 | 无法插入图片 |
| 音频 | 选择插入的音频文件 | 设备本地存储 | 无法插入音频 |
| 涂鸦 | 在白板上绘制的内容 | 设备本地存储 | 无法使用涂鸦功能 |
| 表格 | 插入的表格数据 | 设备本地数据库 | 无法使用表格功能 |
| 提醒时间 | 为笔记设置的提醒时间 | 设备本地数据库 | 无法使用提醒功能 |
| 笔记颜色 | 为笔记选择的便签色 | 设备本地数据库 | 无颜色标记功能 |
| 分类与标签 | 创建的分类、标签组及标签 | 设备本地数据库 | 无法分类管理 |

### 1.2 应用锁 PIN（本地存储，不上传）

为了向您提供应用锁保护服务，您可选择设置 PIN 码。**PIN 经 SHA-256 加盐哈希后存储在设备本地，不可逆，不会上传至任何服务器。**

| 信息类型 | 具体内容 | 存储位置 | 不提供的后果 |
|---------|---------|---------|------------|
| 应用锁 PIN | SHA-256 加盐哈希后的 PIN | 设备本地加密存储 | 无法使用应用锁功能 |

### 1.3 自动收集的信息（仅本机，不上传）

- **设备信息**：Android 版本、设备型号（仅用于兼容性判断，不对外传输）
- **日志信息**：应用崩溃日志（仅本机保存，用于排查问题，不主动上传）

### 1.4 明确不收集的信息

- 账号、邮箱、手机号等身份信息
- GPS 精确位置或粗略位置
- 通讯录、短信、通话记录
- 设备唯一标识（IMEI / IMSI / MAC 地址 / Android ID）
- 联系人、社交关系信息

## 二、权限调用说明

在提供服务过程中，可能会调用您的一些设备权限。以下是我们可能调用的权限以及其所对应的功能说明和目的。

### 2.1 相机权限

在您使用**拍照插入笔记**功能时，需要调用相机权限以便拍摄照片并插入到笔记中。

### 2.2 存储/文件与媒体权限

在您使用**选择图片 / 选择音频 / 导出备份 / 导入备份**功能时，需要调用存储权限以便读取或保存文件。

- 读取图片：从相册选择图片插入笔记
- 读取音频：选择音频文件插入笔记
- 写入存储：导出备份文件、保存导出的图片

### 2.3 通知权限

在您使用**笔记提醒**功能时，需要调用通知权限以便在指定时间发送提醒通知。

### 2.4 网络权限

在您使用**检查更新**功能时，需要调用网络权限以便获取最新版本信息。仅在您主动点击"检查更新"时联网，不会后台自动上传任何数据。

### 2.5 其他权限

| 权限 | 用途 |
|-----|------|
| `VIBRATE` | 提醒振动 |
| `WAKE_LOCK` | 保持 CPU 唤醒以触发提醒 |
| `RECEIVE_BOOT_COMPLETED` | 设备重启后恢复提醒 |
| `FOREGROUND_SERVICE` | 前台服务保活（部分厂商需要） |

所有敏感权限（相机、相册、通知）均在您使用时弹窗申请，您可随时在系统设置中撤销。

## 四、我们如何委托处理、共享、转让、公开披露您的个人信息

### 4.1 委托处理

本应用不涉及将您的个人信息委托给第三方处理的情形。所有数据均在您的设备本地处理。

### 4.2 共享

共享是指我们向其他个人信息控制者提供您的个人信息，且双方分别对个人信息拥有独立的控制权。

**我们原则上不会共享您的个人信息。** 仅在以下情形中可能涉及：

#### 4.2.1 第三方 SDK 说明

本应用集成了以下第三方 SDK，用于提供基础功能。所有 SDK 均**不会在未经您同意的情况下主动采集个人信息**，且数据处理均在您的设备本地完成。

| SDK 名称 | 提供方 | 用途 | 共享数据类型 | 使用场景 | 隐私政策链接 |
|---------|-------|------|------------|---------|------------|
| OkHttp | Square | 网络请求（检查更新） | 无（仅发起 HTTP 请求，不带用户标识） | 手动检查更新时 | [https://square.github.io/okhttp/](https://square.github.io/okhttp/) |
| Retrofit | Square | RESTful HTTP 封装 | 无 | 手动检查更新时 | [https://square.github.io/retrofit/](https://square.github.io/retrofit/) |
| Gson | Google | JSON 解析 | 无（本地解析） | 解析更新信息 / 备份文件 | [https://github.com/google/gson](https://github.com/google/gson) |
| Coil | Coil Contributors | 图片加载 | 无（本地加载） | 加载笔记中的图片 | [https://coil-kt.github.io/coil/](https://coil-kt.github.io/coil/) |
| Room | Google | 本地数据库 | 无（本地存储） | 存储笔记数据 | [https://developer.android.com/jetpack/androidx/releases/room](https://developer.android.com/jetpack/androidx/releases/room) |
| WorkManager | Google | 后台任务 | 无（本地调度） | 提醒调度 | [https://developer.android.com/jetpack/androidx/releases/work](https://developer.android.com/jetpack/androidx/releases/work) |
| Hilt | Google | 依赖注入 | 无（本地使用） | 应用架构 | [https://dagger.dev/hilt/](https://dagger.dev/hilt/) |

请注意，第三方 SDK 可能因为其版本升级、策略调整等原因导致数据处理类型存在一定变化，请以其公示的官方说明为准。

#### 4.2.2 更新检查服务

当您主动点击"检查更新"时，应用会向以下服务发起网络请求以获取最新版本信息：

| 服务名称 | 用途 | 涉及数据 |
|---------|------|---------|
| GitHub Releases API | 检查应用更新 | 公网 API 请求，不带用户标识 |
| Gitee API | 检查应用更新（国内备用源） | 公网 API 请求，不带用户标识 |
| jsDelivr CDN | 获取版本信息（国内备用源） | 公网请求，不带用户标识 |

以上请求**不携带任何个人身份信息**，仅获取最新版本号和下载地址。

#### 4.2.3 法定情形下的共享

基于法律法规规定或按照行政机关、司法机关的强制性要求，共享您的个人信息。

#### 4.2.4 在获取您的同意的情形下共享

经您明确同意后，向指定第三方共享您所授权的部分信息（例如您主动通过系统分享功能导出的笔记）。

除此之外，我们不会将您的个人信息向其他公司、组织或个人进行共享。

### 4.3 转让

我们不会将您的个人信息转让给任何公司、组织和个人，但以下情形除外：

4.3.1 在获取您明确同意的情况下，我们会向其他方转让您的个人信息；
4.3.2 在涉及合并、收购或破产清算时，如涉及到个人信息转让，我们会在要求新的持有您个人信息的公司、组织继续受此个人信息保护政策的约束，否则我们将要求该公司、组织重新向您征求授权同意。

### 4.4 公开披露

个人信息原则上不应公开披露，我们仅会在以下情形中公开披露您的个人信息：

4.4.1 经过您明示授权同意；
4.4.2 依照法律法规及诉讼、公共和政府主管部门有要求的情况下，我们可能会披露您的个人数据。

## 五、我们如何保护您的个人信息

我们已采取符合业界标准、合理可行的安全防护措施保护您的个人信息，防止个人信息遭到未经授权访问、公开披露、使用、修改、损坏或丢失。

### 5.1 技术措施

- **数据隔离**：利用 Android 系统沙箱机制，其他应用无法访问本应用的数据
- **本地存储**：所有数据存储在应用私有目录中，外部应用无法读取
- **应用锁加密**：PIN 码经 SHA-256 + 盐值哈希存储，不可逆
- **数据库安全**：使用 Room / SQLite 本地数据库，不对外暴露

### 5.2 管理措施

- **最小化原则**：仅收集实现功能所必需的最少信息
- **零上传原则**：所有笔记内容、图片、音频均不上传服务器
- **数据可控**：您可随时导出或删除全部数据

### 5.3 数据泄露应急

由于所有数据均存储在您的设备本地，不存在云端数据泄露风险。如您的设备丢失，建议及时通过系统远程擦除功能清除设备数据。

## 六、我们如何存储您的个人信息

### 6.1 存储地点

我们在中华人民共和国境内运营中收集和产生的个人信息，**全部存储在您的移动设备本地**，不传输至境外服务器。

### 6.2 存储期限

- **永久存储**：笔记内容、图片、音频、分类、标签等数据永久存储，直到您主动删除
- **应用锁 PIN**：永久存储，直到您修改或重置应用锁
- **崩溃日志**：仅保存最近一次崩溃信息，应用更新时自动清除

### 6.3 数据删除

- 删除单条笔记：在笔记列表中左滑或长按删除
- 删除全部数据：在「忘记 PIN → 清除所有数据」中删除，或直接卸载应用
- 卸载应用：系统会自动删除应用私有目录中的全部数据

## 七、您的权利

按照中国相关的法律、法规、标准，以及其他国家、地区的通行做法，我们保障您对自己的个人信息行使以下权利。

### 7.1 访问权

您可在应用内查看所有笔记、分类、标签等数据。

### 7.2 更正权

您可随时编辑笔记的标题、正文、图片、音频、颜色、分类、标签等信息。

### 7.3 删除权

- 删除单条笔记：在笔记列表中左滑删除
- 删除全部笔记：通过「忘记 PIN → 清除所有数据」功能删除全部数据
- 卸载应用：卸载即彻底删除全部数据

### 7.4 数据导出权

您可通过「设置 → 数据备份 → 导出备份」将所有笔记导出到本地 JSON 文件，或通过「导出全部笔记为 ZIP」导出为 Markdown 格式的压缩包。

### 7.5 注销权

本应用无账号系统，卸载应用即视为注销，全部数据将被系统删除。

### 7.6 撤回同意权

您可以通过系统设置撤销已授予的权限（如相机、存储、通知等）。撤回同意后，相应功能将无法使用，但不影响此前已进行的信息处理。
