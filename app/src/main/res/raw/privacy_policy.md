# 📜 清笺隐私政策

> 📅 **生效日期**: 2026年06月09日
> 🔄 **最近更新**: 2026年06月09日
> 🏷️ **版本**: v1.0.4

---

## 💡 一分钟速览 (TL;DR)

清笺 是一款**纯本地化**的笔记应用,我们对您的隐私承诺如下:

- ✅ **不上传**: 您的笔记内容**永远不上传**到任何服务器
- ✅ **不收集**: 无需注册账号,不收集邮箱/手机号/位置/通讯录
- ✅ **不追踪**: 不接入广告 SDK,不做用户行为分析
- ✅ **可删除**: 卸载应用即彻底删除全部数据
- ⚠️ **唯一联网**: 仅在您主动点击「检查更新」时,访问 GitHub Releases API

如您对本政策有任何疑问,欢迎通过文末联系方式与我们沟通。

---

## 📌 一、我们收集的信息

### 1.1 ✅ 您主动提供的信息 (本地存储,不上传)

| 信息类型 | 具体内容 |
|---|---|
| 📝 笔记内容 | 标题、正文、列表项、待办项、标签 |
| 🖼️ 图片 | 从相册选择或拍照插入的图片 (本地 URI) |
| 🎵 音频 | 选择插入的音频文件 (本地 URI) |
| 🎨 涂鸦 | 在白板上绘制的图形 |
| 📊 表格 | 插入的表格内容 |
| ⏰ 提醒时间 | 为笔记设置的提醒时间 |
| 🎨 笔记颜色 | 为笔记选择的便签色 |

### 1.2 🔧 自动收集的信息 (仅本机)

- 📱 **设备信息**: Android 版本、设备型号 (仅用于兼容性判断, 不上传)
- 📋 **日志信息**: 应用崩溃日志 (仅本机保存, 不上传)

### 1.3 ❌ 我们不收集的信息 (明确承诺)

- ❌ **账号/邮箱/手机号**: 本应用无账号系统, 无需注册
- ❌ **位置信息**: 不获取 GPS / 精确位置 / 粗略位置
- ❌ **通讯录**: 不读取联系人
- ❌ **短信/通话记录**: 不读取
- ❌ **设备唯一标识 (IMEI/IMSI/MAC)**: 不读取

## 🔍 二、我们如何使用信息

| 信息 | 用途 |
|---|---|
| 笔记内容 | 在本机显示、编辑、保存 |
| 图片 / 音频 | 在笔记中显示、编辑、保存 |
| 涂鸦 / 表格 | 在笔记中显示、编辑、保存 |
| 提醒时间 | 在指定时间通过系统通知提醒您 |
| 设备信息 | 仅用于判断 API 兼容性, 不外传 |

> 🛡️ **郑重承诺**: 我们**不会**将您的笔记内容上传到任何服务器。

---

## 💾 三、信息存储

- 📦 **存储位置**: 所有笔记数据存储在您设备本地的 Room / SQLite 数据库中 (`/data/data/com.example.notes/databases/`)
- ⏳ **存储期限**: 永久存储 (直到您主动删除笔记或卸载应用)
- 🔒 **数据加密**: 利用 Android 系统沙箱隔离, 其它应用无法访问
- ☁️ **备份**: 不自动备份到云端

## 🔐 六、权限申请说明

| 权限 | 用途 | 拒绝影响 |
|---|---|---|
| `INTERNET` | 检查 APP 更新 | 无法检查更新, 其余功能正常 |
| `CAMERA` | 拍照 / 涂鸦 | 无法拍照, 涂鸦仍可用 |
| `RECORD_AUDIO` | (预留) 录音 | (未启用) |
| `READ_MEDIA_IMAGES` (API 33+) | 选图 | 无法选图, 拍照仍可用 |
| `READ_MEDIA_AUDIO` (API 33+) | 选音频 | 无法选音频 |
| `READ_EXTERNAL_STORAGE` (API ≤ 32) | 旧版本读相册 | 无法选图 |
| `WRITE_EXTERNAL_STORAGE` (API ≤ 29) | 旧版本保存图片 | 保存图片失败 |
| `POST_NOTIFICATIONS` (API 33+) | 提醒通知 | 无法收到提醒 |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | 精确提醒 | 提醒可能不准时 |
| `VIBRATE` | 提醒振动 | 提醒无振动 |

> ⚠️ 所有敏感权限 (相机/麦克风/相册/通知) 均在您使用时**弹窗申请**, 您可随时在系统设置中撤销。

## 🤝 七、信息共享

### 7.1 ❌ 我们承诺不会

- ❌ 将您的笔记内容出售给第三方
- ❌ 与广告平台共享您的数据
- ❌ 与任何第三方分析平台共享您的数据

### 7.2 ✅ 我们仅在以下情况共享

- ✅ 您主动通过分享功能导出的笔记
- ✅ 法律法规要求 (如配合司法机关调查)

您对自己的个人信息享有以下权利:

| 权利 | 说明 |
|---|---|
| 🔍 **访问** | 您可在 APP 内查看所有笔记 |
| ✏️ **修改** | 您可编辑笔记的标题/正文/图片/音频/颜色 |
| 🗑️ **删除** | 您可删除单条笔记, 或在「设置 → 清空所有数据」中删除全部 |

| ❌ **注销** | 本应用无账号系统, 卸载应用即视为注销, 全部数据被删除 |
