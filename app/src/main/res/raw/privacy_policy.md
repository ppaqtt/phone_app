# 清笺隐私政策

**生效日期**：2026年06月12日  
**最近更新**：2026年06月18日  
**版本**：v1.20.23

---

## 摘要

清笺是一款**完全本地化**的笔记应用。我们对您的隐私承诺可以概括为一句话：

> **您的数据只属于您。我们不上传、不收集、不追踪。**

| 我们做的 | 我们不做的 |
|---------|-----------|
| 所有数据存储在您设备本地 | 不上传笔记内容到任何服务器 |
| 无需注册账号即可使用 | 不收集邮箱、手机号、位置、通讯录 |
| 仅在您主动点击「检查更新」时联网 | 不接入广告 SDK，不做行为分析 |
| 卸载应用即彻底删除全部数据 | 不出售或共享您的数据给第三方 |

---

## 一、信息收集范围

### 1.1 您主动提供的信息（本地存储，不上传）

| 信息类型 | 具体内容 | 存储位置 |
|---------|---------|---------|
| 笔记内容 | 标题、正文、列表、待办、标签 | 设备本地数据库 |
| 图片 | 从相册选择或拍照插入的图片 | 设备本地存储 |
| 音频 | 选择插入的音频文件 | 设备本地存储 |
| 涂鸦 | 在白板上绘制的内容 | 设备本地存储 |
| 表格 | 插入的表格数据 | 设备本地存储 |
| 提醒时间 | 为笔记设置的提醒时间 | 设备本地数据库 |
| 笔记颜色 | 为笔记选择的便签色 | 设备本地数据库 |
| 应用锁 PIN | SHA-256 加盐哈希后的 PIN | 设备本地加密存储 |

### 1.2 自动收集的信息（仅本机，不上传）

- **设备信息**：Android 版本、设备型号（仅用于兼容性判断）
- **日志信息**：应用崩溃日志（仅本机保存，用于排查问题）

### 1.3 明确不收集的信息

- 账号、邮箱、手机号
- GPS 精确位置或粗略位置
- 通讯录、短信、通话记录
- 设备唯一标识（IMEI / IMSI / MAC 地址）

---

## 二、信息使用方式

| 信息 | 用途 |
|-----|------|
| 笔记内容 | 在本机显示、编辑、保存 |
| 图片 / 音频 / 涂鸦 / 表格 | 在笔记中显示、编辑、保存 |
| 提醒时间 | 在指定时间通过系统通知提醒您 |
| 应用锁 PIN | 验证进入应用或切回前台时的解锁操作 |
| 设备信息 | 仅用于判断 API 兼容性，不外传 |

---

## 三、信息存储与安全

- **存储位置**：所有数据存储在您设备本地的 Room / SQLite 数据库中
- **存储期限**：永久存储，直到您主动删除笔记或卸载应用
- **数据隔离**：利用 Android 系统沙箱机制，其他应用无法访问
- **云端备份**：不自动备份到云端；您可在「设置 → 数据备份」中手动导出到本地 JSON 文件

---

## 四、应用锁（PIN）说明

| 项目 | 说明 |
|-----|------|
| PIN 长度 | 4-8 位，由您自行设置 |
| 存储方式 | SHA-256 + 固定盐值哈希存储，不可逆 |
| 网络传输 | PIN 不会发送到任何服务器 |
| 解锁有效期 | 成功解锁后 5 分钟内回到前台无需再次输入；超过 5 分钟或主动「立即锁定」则重新要求输入 |
| 忘记 PIN | 不提供找回功能（因未上传）；可选择「忘记 PIN → 清除所有数据并重置应用锁」恢复使用（会删除所有笔记，请先备份） |

## 七、权限申请说明

| 权限 | 用途 | 拒绝影响 |
|-----|------|---------|
| `INTERNET` | 检查应用更新 | 无法检查更新，其余功能正常 |
| `CAMERA` | 拍照、涂鸦 | 无法拍照，涂鸦仍可用 |
| `READ_MEDIA_IMAGES`（API 33+） | 选择图片 | 无法选图，拍照仍可用 |
| `READ_MEDIA_AUDIO`（API 33+） | 选择音频 | 无法选音频 |
| `READ_EXTERNAL_STORAGE`（API ≤ 32） | 旧版本读取相册 | 无法选图 |
| `WRITE_EXTERNAL_STORAGE`（API ≤ 29） | 旧版本保存图片 | 保存图片失败 |
| `POST_NOTIFICATIONS`（API 33+） | 提醒通知 | 无法收到提醒 |
| `SCHEDULE_EXACT_ALARM` / `USE_EXACT_ALARM` | 精确提醒 | 提醒可能不准时 |
| `VIBRATE` | 提醒振动 | 提醒无振动 |

所有敏感权限（相机、麦克风、相册、通知）均在您使用时弹窗申请，您可随时在系统设置中撤销。

## 八、信息共享

### 我们不会

- 将您的笔记内容出售给第三方
- 与广告平台共享您的数据
- 与任何第三方分析平台共享您的数据
- 在用户未授权的情况下访问您的通讯录、位置、短信

### 我们仅在以下情况共享

- 您主动通过分享功能导出的笔记
- 法律法规要求（如配合司法机关调查）
