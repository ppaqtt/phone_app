## 🎯 一、服务内容

清笺 是一款本地化笔记应用, 提供以下功能:

| 功能 | 说明 |
|---|---|
| 📝 **笔记记录** | 创建、编辑、保存笔记 (标题/正文/列表/待办) |
| 🖼️ **多媒体附件** | 在笔记中插入图片、音频、涂鸦 |
| 📊 **表格** | 在笔记中插入可编辑的 Excel 风格表格 |
| 🎨 **富文本格式** | 文字加粗、斜体、下划线、删除线、字号、颜色、段落对齐 |
| ⏰ **提醒功能** | 为笔记设置定时提醒通知 |
| 🔄 **检查更新** | 通过 GitHub Releases API 检查 APP 是否有新版本 |
| 💬 **问题反馈** | 通过腾讯文档收集用户反馈 |
| 📤 **导入导出** | 通过系统分享功能导入/导出笔记 |
